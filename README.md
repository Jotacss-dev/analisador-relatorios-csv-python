# Analisador de Relatórios CSV

Projeto em Python que lê registros de atividades em CSV e gera indicadores de
produtividade para equipes e profissionais remotos.

## Recursos

- leitura e validação de arquivos CSV;
- cálculo de horas por responsável e categoria;
- contagem de atividades por status;
- cálculo da taxa de conclusão;
- geração de relatório em texto;
- arquivo de exemplo e teste automatizado.

## Como executar

```bash
python analisador_relatorios.py atividades_exemplo.csv
python -m unittest -v
```
